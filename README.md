# BridgeLink 4.7 官网

BridgeLink 的产品官网，单页站点，纯静态（HTML + CSS + 原生 JS），无构建步骤、无框架依赖。

## 运行

直接双击 `index.html` 即可预览；或起一个本地服务（推荐，避免个别浏览器对 `file://` 的限制）：

```bash
python -m http.server 8899
# 打开 http://127.0.0.1:8899
```

## 目录

```
bridgelink_site/
├─ index.html              页面结构（全部内容）
├─ assets/
│  ├─ css/style.css        设计系统 + 全部组件样式 + 动效关键帧
│  ├─ js/main.js           交互与过渡动效
│  └─ img/app_icon.png     应用图标（取自软件包）
└─ _shots/                 渲染截图（验证用，可删）
```

## 设计系统

配色令牌与应用内 `BridgeLink/bridgelink/ui/theme.py` 同源，改一处两边同步。

- **主题**：浅色 / 深色 / 午夜 / 北欧极简 / 柔和暖阳 / 跟随系统 —— 与软件内 6 套主题一一对应，
  右侧「外观定制」板块可实时切换预览。
- **强调色**：蓝 / 绿 / 紫 / 橙 / 粉 / 红 —— 点击导航栏色块或主题板块的色板即可全局切换，
  通过 CSS 变量 `color-mix()` 实时派生浅色底与前景色。
- 令牌定义在 `style.css` 顶部的 `:root` 与 `[data-theme]` / `[data-accent]` 选择器中。

## 交互演示说明

「交互演示」板块的虚拟大屏布局图可以直接**拖动设备方块**换位置，
被占用的格子会自动与对方互换 —— 与软件内交互一致。

## 已知事项

- 字体使用 Google Fonts（Inter / JetBrains Mono），离线时会回退到系统字体栈，版式不会错乱。
- 下载按钮与「查看源码」目前为占位链接，指向实际发布地址后即可生效。
- 剪贴板复制依赖 `navigator.clipboard`，在非安全上下文（如 `file://`）下会自动回退到
  `execCommand`，两者都不可用时提示「复制失败」。
